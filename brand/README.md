# statcan2 brand

Every file here and in `api/public/brand/` is generated by `node brand/build.mjs`. The script needs `api/node_modules` (it uses `@resvg/resvg-js` and the `geist` fonts) and ImageMagick `magick` (for `favicon.ico`). All SVGs use paths only. They need no fonts.

## Mark

A rising line that ends in a red dot, white on an ink tile. It is the chart motif from the banners and OG cards: the red dot is the latest value. The mark is about the data, not the `(2)`, so `(2)` stays a wordmark suffix that other projects can share. Two drawings:

- **Large** (`logo-mark.svg`): five points, a 7-unit line. Use it at 48 px and up.
- **Small** (`logo-mark-small.svg`, `favicon.svg`, `favicon.ico`, the site top bar): four points, an 11-unit line, a bigger dot. Use it at 16–32 px.

App icons and avatars (`apple-touch-icon.png`, `icon-*.png`, `profile-*.png`) fill the whole square with ink, because the platform crops the corners.

Wordmark (`logo-wordmark.svg`): `statcan` in Geist 600 ink, then `(2)` in Geist Mono 500 red, on one baseline. The site top bar shows the small mark, 20 px, then this wordmark.

Earlier concepts a–d (the `(2)`, `s2`, a line in parentheses, bars) stay in `concepts/` for comparison.

## Colours

| Name | Hex | Use |
| --- | --- | --- |
| Ink | `#0E0F11` | the `2`, `statcan` |
| Accent | `#D80621` | the parentheses, `(2)` |
| Paper | `#FFFFFF` | background |
| Dark-mode accent | `#FF3B4E` | `favicon.svg` only, under `prefers-color-scheme: dark` (the tile turns white and the line ink) |

The values come from `COLORS` in `api/public/export-layout.js`. Red is never a background fill.

## Clear space and minimum size

- Clear space: keep space equal to the height of the `2` on every side of the mark. For the wordmark, keep the height of `(2)` on every side.
- Minimum size: mark 16 px (small drawing); wordmark 80 px wide.
- Do not recolour, outline, rotate or put the mark on a coloured or photographic background.

## Which file goes where

| File | Use |
| --- | --- |
| `api/public/brand/favicon.svg` | `<link rel="icon" type="image/svg+xml">`, transparent, with a dark-mode variant |
| `api/public/brand/favicon.ico` | 16, 32, 48 px fallback |
| `api/public/brand/apple-touch-icon.png` | iOS home screen, 180 px, white, 12 % padding |
| `api/public/brand/icon-192.png`, `icon-512.png` | web manifest icons |
| `api/public/brand/icon-maskable-512.png` | web manifest, `purpose: maskable`; the mark sits inside the 80 % safe circle |
| `api/public/brand/site.webmanifest` | the manifest |
| `brand/profile-1000.png` | X, LinkedIn, Bluesky, GitHub avatar; survives a circle crop |
| `brand/profile-400.png` | the same, for upload limits or small slots |
| `brand/header-x-1500x500.png` | X header; text stays out of the bottom-left avatar area |
| `brand/header-linkedin-1584x396.png` | LinkedIn page banner |
| `brand/logo-mark.svg`, `logo-mark-small.svg` | the mark as vectors |
| `brand/logo-wordmark.svg` | `statcan(2)` as a vector |
| `brand/concepts/` | the three concepts and `contact-sheet.png` (every size, crop checks, both headers) |
