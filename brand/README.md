# statcan2 brand

Every file here and in `api/public/brand/` is generated by `node brand/build.mjs`. The script needs `api/node_modules` (it uses `@resvg/resvg-js` and the `geist` fonts) and ImageMagick `magick` (for `favicon.ico`). All SVGs use paths only. They need no fonts.

## Mark

A maple leaf drawn as an area chart: red on white, inside a black axis on the left and bottom (6/100 wide). The window runs from the centre lobe's left tip to the right lobe's outer tip, so the heavy part of the leaf stands against the y axis and the red fills down to the x axis. Cropped like this, it reads as a chart, and the centre lobe and side lobe still say maple leaf. The mark is square, like everything else on the site. Only the favicon (`favicon.svg`, `favicon.ico`) rounds its corners, by 6/100 of its width. The mark is about the data, not the `(2)`, so `(2)` stays a wordmark suffix that other projects can share.

One drawing (concept f in `build.mjs`) serves every size. `logo-mark.svg` (512 px) and `logo-mark-small.svg` (32 px) differ only in their declared size. On the site's white pages (the top bar, the OG site card) the white tile is not drawn. Padded icons shrink the whole chart, axis included, into the middle.

App icons and avatars (`apple-touch-icon.png`, `icon-*.png`, `profile-*.png`) are square and white edge to edge, because the platform crops the corners.

Wordmark (`logo-wordmark.svg`): `statcan` in Geist 600 ink, then `(2)` in Geist Mono 500 red, on one baseline. The site top bar shows the mark, 20 px, then this wordmark, with the mark's x axis on the wordmark's baseline. The OG site card (`/og/site.png`) shows the same pair at 72 px.

Earlier concepts a–e (the `(2)`, `s2`, a line in parentheses, bars, a rising line with a red dot) stay in `concepts/` for comparison.

## Colours

| Name | Hex | Use |
| --- | --- | --- |
| Ink | `#0E0F11` | the axis, `statcan` |
| Accent | `#D80621` | the leaf, `(2)` |
| Paper | `#FFFFFF` | the tile, background |

The values come from `COLORS` in `api/public/export-layout.js`. Red fills only the leaf; it is never a page or tile background. The mark has no dark variant: its white tile reads on dark tab bars too.

## Clear space and minimum size

- Clear space: keep a quarter of the tile's width clear on every side of the mark. For the wordmark, keep the height of `(2)` on every side.
- Minimum size: mark 16 px (small drawing); wordmark 80 px wide.
- Do not recolour, outline, rotate or put the mark on a coloured or photographic background.

## Which file goes where

| File | Use |
| --- | --- |
| `api/public/brand/favicon.svg` | `<link rel="icon" type="image/svg+xml">`, white tile with 6/100 rounded corners, the same in dark mode |
| `api/public/brand/favicon.ico` | 16, 32, 48 px fallback |
| `api/public/brand/apple-touch-icon.png` | iOS home screen, 180 px, white, 12 % padding |
| `api/public/brand/icon-192.png`, `icon-512.png` | web manifest icons |
| `api/public/brand/icon-maskable-512.png` | web manifest, `purpose: maskable`; the mark sits inside the 80 % safe circle |
| `api/public/brand/site.webmanifest` | the manifest |
| `brand/profile-1000.png` | X, LinkedIn, Bluesky, GitHub avatar; survives a circle crop |
| `brand/profile-400.png` | the same, for upload limits or small slots |
| `brand/header-x-1500x500.png` | X header; text stays out of the bottom-left avatar area |
| `brand/header-linkedin-1584x396.png` | LinkedIn page banner |
| `brand/logo-mark.svg`, `logo-mark-small.svg` | the mark as vectors |
| `brand/logo-wordmark.svg` | `statcan(2)` as a vector |
| `brand/concepts/` | the earlier concepts and `contact-sheet.png` (every size, crop checks, both headers) |
